# Browse Races Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Browse its own view (back link + "Choose an election" H1, no hero/address box) and restyle its filter panel, count and section headers to Aditi's prototype, keeping `RaceCard` unchanged.

**Architecture:** A new `BrowseHeader` component (back link + H1, scroll/focus on mount) is rendered by `RaceHub`'s browse branch. `RaceHub` and `Landing` hide their own header/hero/address/switch while `browseTarget` is set; `Landing` scrolls back to the picker when Browse closes. `RaceBrowse` gets a panel wrapper, a pin-labelled state select, a bold count and icon section headers; CSS moves to tokens.

**Tech Stack:** React 19 + TypeScript, Zustand store (`useReadRankStore`), framer-motion (`useMotion`), plain CSS with tokens in `src/index.css` (Tailwind v4 utilities available), Vitest + Testing Library.

Spec: `docs/superpowers/specs/2026-10-07-browse-design.md`.

## Global Constraints

- `RaceCard`, `race-grid`, `raceCardProgress`, search/haystack/synonyms, office filter logic, `initial` state preset, rankable-only filter, the empty-state text, analytics and the store shape (`browseTarget`) are unchanged.
- Tokens only in new/changed CSS and components — no hex literals, no `rgba(` in component files, no Tailwind `dark:` classes.
- Back link text: "‹ Back to my ballot" when `locationFilter !== null`, otherwise "‹ Back". It calls `setBrowseTarget(null)`.

- New token `--focus-ring`: `:root` `rgba(0, 83, 102, 0.18)`, `.dark` `rgba(89, 176, 196, 0.28)`.
- Section `aria-label`: "{label}, {n} race" / "{label}, {n} races".

- [ ] **Step 3: Implement `BrowseHeader`**

`src/components/BrowseHeader.tsx`:

```tsx
import { useEffect, useRef } from 'react';

interface BrowseHeaderProps {
  /** "‹ Back to my ballot" with a location, otherwise "‹ Back". */
  backLabel: string;
  onBack: () => void;
}

/** Top of the Browse view: a text back link and the page H1. On mount it scrolls to
 *  the top and moves focus to the H1, so Browse reads as its own page. */
export function BrowseHeader({ backLabel, onBack }: BrowseHeaderProps) {
  const titleRef = useRef<HTMLHeadingElement>(null);

  useEffect(() => {
    window.scrollTo({ top: 0 });
    titleRef.current?.focus({ preventScroll: true });
  }, []);

  return (
    <div className="rr-browse-header">
      <button type="button" className="rr-browse-back" onClick={onBack}>{backLabel}</button>
      <h1 ref={titleRef} tabIndex={-1} className="rr-browse-title">Choose an election</h1>
    </div>
  );
}
```
